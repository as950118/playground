# practice-vision

카메라 기반 생체 신호·비전 관련 실습을 모아 두는 저장소입니다. 각 주제는 **자료 리서치 → 예시 코드 → 코드로부터 인사이트 정리** 순서로 진행합니다.

## 구성

| 주제 | 디렉터리 | 상태 |
|------|-----------|------|
| Remote PPG (rPPG) | [`rppg/`](./rppg/) | 진행 중 |
| EVM (Eulerian Video Magnification) | (예정) | 미착수 |

## 공통 진행 방식

1. **리서치**: 논문·서베·오픈소스 구현을 읽고 용어·파이프라인·한계를 정리합니다 (`docs/RESEARCH.md`).
2. **예시 코드**: 의존성을 최소화한 스크립트로 한 가지 흐름을 끝까지 돌려 봅니다 (`examples/`).
3. **인사이트**: 구현 과정에서 드러난 가정, 튜닝 포인트, 다음 실험 아이디어를 적습니다 (`docs/INSIGHTS.md`).

## 요구 사항

- 주제별로 `requirements.txt`를 따릅니다. rPPG는 Python 3.10+ 권장입니다.

## 라이선스

예시 코드는 학습용으로 두었습니다. 상업·임상 용도는 별도 검증이 필요합니다.

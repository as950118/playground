# playground

| 폴더 | 내용 | 원래 저장소 |
|---|---|---|
| [`java/`](java/) | Java 실습 (virtual thread 등, Gradle) | `practice-java` |
| [`kafka/`](kafka/) | Kafka 3.8 KRaft 클러스터 실습 + 압축 코덱 벤치마크 | `practice-kafka` |
| [`vision/`](vision/) | 컴퓨터 비전 실습 (rPPG 심박 추정) | `practice-vision` |
| [`prometheus-thanos/`](prometheus-thanos/) | Prometheus 단독 / Thanos Sidecar / Thanos Receive 구성 비교 스터디 | `prometheus-and-thanos` |
| [`k8s-networking/`](k8s-networking/) | Kubernetes 네트워킹(kube-proxy iptables/IPVS) 동작 분석 | `k8s-networking` |
